# Brand Identity Research: 3D Apartment Guest Assistant

Research date: 2026-11-19. Status: **recommendation only. Not approved. Nothing purchased, registered or created.**

## 1. How the research was done

| Check | Method | Reliability |
|---|---|---|
| .com availability | Verisign RDAP (the .com registry's own lookup service, `rdap.verisign.com`). HTTP 404 = no registration record, 200 = registered. Method sanity-checked against known-taken and random names. | High for "is it registered". It does **not** prove the name is buyable at standard price (registry-reserved or premium names can still show 404). **Confirm at a registrar before relying on it.** |
| Alternative extensions | Not needed: every shortlisted name has an unregistered .com. (Quick .net probe returned redirects only, not used.) | n/a |
| App Store | Apple iTunes Search API, term search, top results inspected | High for exact-name conflicts (none found) |
| Google Play | Web search only (Play has no public search API) | Low. Re-check manually in Play Console / store search |
| Trademarks | Web search of public aggregators (Justia, Markinton, TrademarkDir). **Official USPTO/EUIPO/WIPO search was NOT queried** (needs an interactive browser session). | Low-medium. This is an indicator, not clearance |
| Social usernames | GitHub API (reliable). YouTube, TikTok, Reddit, Pinterest, Medium, npm, Instagram, X return uniform responses or block automated checks, so they are **unverified** | GitHub only |

Screening funnel:
- 15 initial ideas (Arrivo, Stayra, Nestora, Keyloom, Roomvia, Lodgely, Vuenest, Casalume, Hostara, Stayvue, Welcomi, Roomori, Halvio, Stayloom, Unlockr): **all 15 .coms already registered.**
- About 60 more dictionary-style blends, checked one at a time: none free.
- About 560 coined names screened in parallel: about 110 unregistered. Most were unpronounceable, so 15 pronounceable ones were shortlisted below.

Takeaway: short, natural hospitality names are gone on .com. The names below are coined words, which is also better for trademark strength.

## 3. Five strongest and why

1. **Welcovue** (welco-vue). Best concept fit: *welcome* is the heart of hospitality and *vue* signals the visual, 3D experience. Not tied to apartments, so it stretches to hotels and resorts. Weakness: guests may type "Welcoview"; consider registering that variant later if available.
2. **Lodgevia**. Reads as a premium lodging brand. "Via" implies guidance, which matches the instructions and appliance guidance. Weakness: sits near LODGIFY and LODGIQ in sound and category, so a lawyer should check.
3. **Hostavue**. Speaks directly to the buyer (property managers and hosts). Weakness: less guest-facing warmth; slightly clunky "-avue".
4. **Suitevio**. Upmarket, hotel-ready. Weakness: sounds less like a tech product and could be misspelled as "Suitevio / Suitevivo".
5. **Welcovia**. Friendly and easy to pronounce. Weakness: close to Welcovue, and weaker link to the 3D / visual idea.

## 4. Recommendation

**Welcovue**, preferred domain **welcovue.com**.

Reasons: strongest meaning-to-product match, coined (so legally strong and ownable), pronounceable internationally, no exact-name hits in app stores or trademark aggregators, .com and GitHub handle free.

Runner-up: **Lodgevia** (lodgevia.com).

Observation: after four rounds, short natural hospitality names are essentially exhausted on .com. If none of the candidates satisfies, the realistic options are (a) accept a compound such as Nooktour or Velkoma, (b) use a non-.com extension (.io, .co, .app) for a stronger name, or (c) negotiate to buy a premium name through a broker. None has been done.
